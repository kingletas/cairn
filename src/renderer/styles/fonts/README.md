# Bundled typefaces

Cairn ships these rather than fetching them, because a font request from a CDN is a
network request the user did not ask for and the outbound counter would never see.

| Family | Designer | Licence |
|---|---|---|
| **IBM Plex Sans** | Mike Abbink, Bold Monday, for IBM | [SIL Open Font License 1.1](https://github.com/IBM/plex/blob/master/LICENSE.txt) |
| **IBM Plex Mono** | Mike Abbink, Bold Monday, for IBM | [SIL Open Font License 1.1](https://github.com/IBM/plex/blob/master/LICENSE.txt) |
| **Newsreader** | Production Type | [SIL Open Font License 1.1](https://github.com/productiontype/Newsreader/blob/master/OFL.txt) |

All three are under the SIL Open Font License 1.1, which permits bundling and
redistribution with an application. The files here are the latin and latin-ext subsets
only — sixteen faces over eight files, about 370 kB in total.

**Cairn's own MIT licence does not cover these.** They keep their own, which is why
this file exists.
